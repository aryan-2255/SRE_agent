# System map: astronomy-shop

Generated by scripts/map_system.py from https://github.com/aryan-2255/opentelemetry-demo. Architecture for the agents; check code before relying on details.

Domain: e-commerce. Shared code: pb, src/shared (protobuf contracts and libraries used by several services).

## Request flow

- frontend calls cart, checkout, product-catalog, recommendation, ad, currency, shipping
- checkout calls payment, cart, product-catalog, shipping, email, currency, kafka
- cart calls valkey-cart
- recommendation calls product-catalog
- shipping calls quote
- accounting calls kafka
- fraud-detection calls kafka
- agent calls product-catalog
